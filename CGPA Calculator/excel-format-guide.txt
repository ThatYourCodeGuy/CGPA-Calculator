CGPA Calc — Excel File Format Guide
=====================================

When exporting from CGPA Calc, the .xlsx file contains 4 sheets:

SHEET 1: "Student Info"
  Row 1:  Full Name        | Adaeze Okonkwo
  Row 2:  Matric Number    | CSC/2021/001
  Row 3:  Department       | Computer Science
  Row 4:  Level            | 200 Level
  Row 5:  Grading Scale    | 5.0 Scale
  Row 6:  Overall CGPA     | 4.23
  Row 7:  Classification   | Upper Credit
  ...

SHEET 2: "All Courses" (main data — used for import)
  Columns: Semester | Course Name | Units | Grade | Grade Points | ...
  Example rows:
    100L First Semester | Use of English          | 2 | A | 10
    100L First Semester | Calculus I              | 3 | B | 12
    100L First Semester | Intro to Computer Sci   | 3 | A | 15
    (blank row between semesters)
    100L Second Semester| Introduction to Prog    | 3 | A | 15
    ...

SHEET 3: "Semester Summary"
  Semester | Courses | Sem Units | Sem GP | Semester GPA | Cumulative Units | ...

SHEET 4: "Grade Distribution"
  Grade | Count | Grade Points Value

IMPORTING YOUR OWN EXCEL FILE
==============================
To import a custom Excel file, it must have at minimum ONE sheet with these columns:
  - A column with "Semester" in the header (e.g. "Semester", "Sem")
  - A column with "Course" or "Name" in the header
  - A column with "Unit" in the header
  - A column with "Grade" in the header (values: A, B, C, D, E, F)

The importer will auto-detect column positions — column order doesn't matter.
